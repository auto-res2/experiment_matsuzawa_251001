# Paper Outline
AUTOMATA is a three-component framework: a hyper-parameter search algorithm (e.g., Random Search, TPE), a gradient-based subset selection (GSS) algorithm for efficient configuration evaluation, and a hyper-parameter scheduling algorithm (e.g., Hyperband, ASHA) for early stopping. The core of AUTOMATA is the GSS, which selects a subset S and its weight vector w such that the weighted subset loss gradient best approximates the entire training loss gradient. This optimization problem, formulated as minimizing the L2 norm of the gradient difference plus a regularization term, is approximately submodular and solved using a greedy algorithm called Orthogonal Matching Pursuit (OMP). A 'per-batch' subset selection is employed for efficiency, where a subset of mini-batches is selected instead of individual data points. Model warm-starting is also used for ASHA scheduler experiments to provide informative loss gradients for selection.
