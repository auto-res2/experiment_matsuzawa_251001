# Paper Outline
CPL builds a learnable neural network model, xϕ(t), that maps any continuation level t to its corresponding solution. The method reformulates the traditional unidirectional homotopy optimization into a single-loop model training problem, minimizing the expected homotopy function H(xϕ(t), t) over t. Training is performed using stochastic gradient descent with Monte Carlo sampling for t. Gradients are computed via the chain rule, with ∂xϕ(t)/∂ϕ determined by backpropagation and ∇xH(x, t) either analytically, through a zeroth-order Evolutionary Strategy approximation, or a specific Gaussian homotopy approximation. An optional local search, initialized with solutions from the learned path, can be applied for specific homotopy levels. For Neural Combinatorial Optimization (NCO), the policy model's parameters (specifically query and projection parameters in the Attention Model decoder) are dynamically conditioned on t via a multi-layer perceptron. NCO models are trained using REINFORCE with POMO rollout and inference involves sampling multiple continuation levels to generate and select the best solution for the original problem.
