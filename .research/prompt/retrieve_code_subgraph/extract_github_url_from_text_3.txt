This simplification is motivated by theoretical analysis linking the excess empirical risk of private Gradient Descent (GD) to a 'noisy radius,' which is shown to be proportional to `η × T`. The method estimates the optimal `r` for a given privacy budget `ε` by sampling `r(ε)` at two distinct, small privacy budgets (e.g., `ε1 = 0.1, ε2 = 0.2`) using random search (cheap trials). A linear function (`r = mε + b`) is then fitted to these two points to approximate the relationship between `r` and `ε`, allowing for the estimation of `r` for any target `εf`. The estimated `r*` is subsequently decomposed back into `η` and `T`. Key design choices for private training include using full-batch gradient descent (DP-GD) to maximize the signal-to-noise ratio of updates, unit clipping (C=1) for per-sample gradients to avoid optimization bias, zero initialization for linear classifier weights, and integrating momentum (ρ=0.9) to accelerate convergence.
