FEDHPO-B is designed as a benchmark suite upon the FederatedScope (FS) FL platform, encapsulating FL tasks as functions to be optimized. It provides a unified interface for HPO methods with three function evaluation modes: (1) 'Tabular' mode uses pre-computed lookup tables generated by executing FL algorithms on a grid search space, with averaged results over multiple random seeds for both full and multi-fidelity evaluations. (3) 'Raw' mode executes the FL algorithm directly within an FS Docker container and integrates a configurable system model to estimate realistic execution time, accounting for communication bottlenecks (server broadcasting, client upload/download) and client computational heterogeneity (modeled by an exponential distribution for straggler estimation).
