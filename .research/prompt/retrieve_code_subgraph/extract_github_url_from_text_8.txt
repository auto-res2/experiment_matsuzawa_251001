# Paper Outline
DyHPO employs a Gaussian Process (GP) surrogate model with a novel deep kernel. This deep kernel, `K(θ, w)`, takes as input the hyperparameter configuration `xi`, the budget `j`, and the past learning curve `Yi,j-1`. A neural network, `φ`, acts as a feature extractor, processing concatenated `xi` and normalized `j` through linear layers, and the learning curve `Yi,j-1` via a one-dimensional convolution followed by global max pooling. The outputs are then fed to a squared exponential (RBF) kernel `k`. Model parameters `θ` and `w` are optimized by maximizing marginal likelihood using Adam with a learning rate of 0.1. The acquisition function is a Multi-Fidelity Expected Improvement (EIMF), which extends the standard Expected Improvement by incorporating a budget-aware incumbent `ymax_j`. The algorithm dynamically selects configurations to train for one additional budget step based on `EIMF` and updates the surrogate model with observed validation scores.
