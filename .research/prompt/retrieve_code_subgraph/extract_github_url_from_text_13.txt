# Paper Outline
DyHPO is a Bayesian Optimization (BO) method utilizing Gaussian Processes (GP) as a surrogate model. It employs a novel deep kernel for the GP, which takes the hyperparameter configuration, budget information, and the *past learning curve* as explicit inputs. The deep kernel uses a neural network (composed of linear and convolutional layers, and global max pooling) to process these inputs into a feature representation, which then feeds into a squared exponential kernel. The model parameters for the kernel and neural network are optimized by maximizing the marginal likelihood. For selecting the next configuration, DyHPO uses a proposed Multi-Fidelity Expected Improvement (EIMF) acquisition function that dynamically decides which candidate configuration to train for a small, incrementally increased budget at each HPO step.
