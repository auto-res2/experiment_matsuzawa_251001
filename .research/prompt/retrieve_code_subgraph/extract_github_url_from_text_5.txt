# Paper Outline
DNN-MFBO uses a stacked neural network architecture where each NN models one fidelity. For fidelity m > 1, the NN input includes both the original objective input and the output from the previous fidelity (fm-1(x)). The output layer weights (wm) of each NN are treated as random variables with a standard normal prior, while other weights (θm) are hyper-parameters. A stochastic variational learning algorithm is developed to jointly estimate the posterior of random weights (q(wm) = N(wm|µm, Σm)) and hyper-parameters by maximizing an ELBO. To compute the acquisition function, fidelity-wise moment matching and Gauss-Hermite quadrature approximate the output posteriors p(fm(x)|D) as Gaussian distributions. A mutual information-based acquisition function (Max-Value Entropy Search, MES) is used, requiring Monte-Carlo approximation for the conditional entropy term and further moment matching to approximate conditional posteriors as Gaussian for analytical entropy calculation. Automatic differentiation and L-BFGS are used for acquisition function optimization.
