DyHPO is built upon Gaussian Process (GP) based Bayesian Optimization. It uses a deep kernel that explicitly takes the hyperparameter configuration, past learning curve, and budget information as input. The deep kernel's feature extractor employs linear layers and a one-dimensional convolutional layer with global max pooling for processing the learning curve. The method utilizes a Multi-Fidelity Expected Improvement (EIMF) acquisition function to dynamically select the next promising configuration and its incremental budget for evaluation. The algorithm iteratively expands the training budget for selected candidates, adds new observations, and updates the surrogate model.
